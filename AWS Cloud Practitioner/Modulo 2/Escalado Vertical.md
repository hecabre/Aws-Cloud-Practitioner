# Escalado vertical

El escalado vertical consiste en aumentar la capacidad de una máquina o instancia existente, por ejemplo, mediante más CPU o memoria. En [[Amazon EC2]], normalmente implica cambiar a un tipo de instancia más grande.

## Ventaja

Proporciona más potencia por instancia sin distribuir la aplicación entre varias máquinas.

## Consideraciones

- Está limitado por el tamaño máximo disponible para el recurso.
- Según el servicio y el cambio realizado, puede requerir una interrupción.
- Mantiene la dependencia de una sola instancia si no se combina con una arquitectura de alta disponibilidad.
