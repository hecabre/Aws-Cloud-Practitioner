# Hipervisor

El **hipervisor** es un software de virtualización que gestiona y asigna los recursos físicos de hardware a múltiples máquinas virtuales de forma **aislada y segura**.

Es la capa que permite que un solo equipo físico ejecute varias instancias al mismo tiempo.
