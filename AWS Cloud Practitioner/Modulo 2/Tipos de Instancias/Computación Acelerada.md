# Instancias de Computación Acelerada

Usan **aceleradores de hardware**, como GPU, FPGA o chips especializados.

## Casos de uso

- Cálculos con números de punto flotante.
- Procesamiento gráfico.
- Coincidencia o detección de patrones en los datos.
- Machine learning e inteligencia artificial.
