# Escalabilidad

La escalabilidad es la capacidad de un sistema para soportar un aumento de usuarios, datos o carga de trabajo mediante la incorporación de recursos.

## Tipos de escalabilidad

- **[[Escalado Vertical]]:** aumenta la capacidad de un recurso existente.
- **[[Escalado Horizontal]]:** agrega más recursos que trabajan en conjunto.

La escalabilidad puede aplicarse de forma manual o automática y permite planificar el crecimiento de una carga de trabajo.

## Diferencia con elasticidad

Un sistema escalable puede crecer para soportar más carga. Un sistema con [[Elasticidad]] ajusta sus recursos hacia arriba o hacia abajo conforme cambia la demanda actual o prevista.
