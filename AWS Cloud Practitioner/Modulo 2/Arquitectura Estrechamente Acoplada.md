# Arquitectura estrechamente acoplada

En una arquitectura estrechamente acoplada, los componentes dependen directamente unos de otros.

Un cambio en la interfaz o el comportamiento de un componente puede exigir cambios en los componentes dependientes. Del mismo modo, un fallo puede propagarse y degradar una parte mayor del sistema.

Este tipo de dependencia es frecuente en [[Aplicaciones Monoliticas|aplicaciones monolíticas]], aunque una aplicación monolítica no tiene que estar mal estructurada ni ser siempre la opción incorrecta.
