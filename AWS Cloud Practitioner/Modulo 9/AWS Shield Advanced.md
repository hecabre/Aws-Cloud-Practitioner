# AWS Shield Advanced

## ¿Qué es?

Es una suscripción de protección ampliada contra ataques DDoS para recursos compatibles. Proporciona detección y mitigación adicionales, visibilidad detallada de los ataques y acceso al equipo de respuesta de AWS Shield.

Se integra con servicios como [[AWS Cloud Practitioner/Modulo 5/Amazon Cloudfront|Amazon CloudFront]], [[Amazon Route 53]] y [[Elastic Load Balancing]].
