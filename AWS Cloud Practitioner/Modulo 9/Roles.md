# Roles de IAM

## ¿Qué son?

Los roles de IAM son identidades con políticas de permisos que pueden ser asumidas por entidades de confianza. No tienen credenciales permanentes propias; al asumir un rol se obtienen credenciales de seguridad temporales.

Son útiles para delegar acceso entre cuentas, conceder permisos a servicios de AWS o permitir que cargas de trabajo externas, como una acción de GitHub, accedan a recursos sin guardar claves de acceso de larga duración.
