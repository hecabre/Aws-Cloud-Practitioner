# AWS IAM

## ¿Qué es?

AWS Identity and Access Management (IAM) permite controlar quién está autenticado y qué acciones puede realizar sobre los recursos de AWS.

De forma predeterminada, las solicitudes se deniegan. Los permisos se conceden explícitamente mediante políticas JSON que especifican acciones, recursos y, de manera opcional, condiciones. El principio de **privilegio mínimo** indica que cada identidad debe recibir sólo los permisos necesarios para su tarea.
