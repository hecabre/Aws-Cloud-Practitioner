# Amazon GuardDuty

## ¿Qué es?

Es un servicio de detección de amenazas que supervisa continuamente fuentes de datos y registros de AWS para identificar actividad maliciosa o no autorizada. Utiliza inteligencia de amenazas, detección de anomalías y machine learning para generar hallazgos priorizados.

Los hallazgos incluyen contexto para investigar y responder. La corrección puede automatizarse mediante servicios como [[Aws Lambda]] y Amazon EventBridge.
