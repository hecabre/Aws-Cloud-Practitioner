# AWS Systems Manager

## ¿Qué es?

Es un servicio de administración que proporciona visibilidad y control sobre nodos de AWS y de entornos híbridos y multinube. Permite consultar información de los nodos y automatizar tareas operativas como aplicar parches, ejecutar comandos y administrar configuraciones.

Un **nodo administrado** es una máquina configurada para utilizar Systems Manager, como una instancia de [[Amazon EC2]] o un servidor de otro entorno.
