# AWS Key Management Service (AWS KMS)

## ¿Qué es?

AWS KMS permite crear y controlar claves criptográficas para cifrar, descifrar y firmar datos. Se integra con numerosos servicios de AWS y permite definir qué usuarios y roles pueden administrar o utilizar las claves.

Una **clave criptográfica** es un valor utilizado por un algoritmo para realizar operaciones como el cifrado y descifrado de datos.
