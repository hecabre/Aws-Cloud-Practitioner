# Subredes

Una **subred** es un rango de direcciones IP dentro de una [[Amazon VPC]]. Se utiliza para organizar recursos y puede ser pública o privada según su tabla de enrutamiento.

Por lo general, una subred privada contiene recursos que no deben exponerse directamente a Internet, como una base de datos. Una subred pública puede contener recursos orientados al cliente, como un sitio web, si tiene una ruta a una puerta de enlace de Internet y los recursos cuentan con direcciones y reglas de seguridad adecuadas.
