# Puerta de enlace privada virtual

Una **puerta de enlace privada virtual** es el componente del lado de AWS que permite establecer una conexión de AWS Site-to-Site VPN entre una VPC y una red local o privada aprobada.

La conexión VPN utiliza túneles cifrados. El tráfico solo puede llegar a los recursos permitidos por el enrutamiento y los controles de seguridad configurados.
