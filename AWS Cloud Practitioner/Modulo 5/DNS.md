# DNS

El **Sistema de nombres de dominio (DNS)** traduce nombres de dominio a destinos, como direcciones IP.

El cliente consulta un resolvedor DNS, que puede obtener la respuesta desde su caché o consultar servidores DNS jerárquicos. En AWS, el Route 53 Resolver proporciona resolución DNS para las VPC y permite definir reglas de reenvío hacia o desde redes locales.
