# Amazon API Gateway

**Amazon API Gateway** es un servicio de AWS para crear, publicar, mantener, supervisar y proteger API a cualquier escala.

Admite API REST, API HTTP y API WebSocket. Puede actuar como puerta de entrada para servicios backend como AWS Lambda o aplicaciones HTTP, y permite configurar autenticación, autorización, limitación de solicitudes, monitoreo y despliegues por etapas.
