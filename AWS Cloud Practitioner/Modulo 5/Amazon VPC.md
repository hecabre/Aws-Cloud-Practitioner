# Amazon VPC

Una **Amazon VPC** permite aprovisionar una sección lógicamente aislada de la nube de AWS, donde se pueden lanzar recursos en una red virtual definida por el usuario.

Una VPC pertenece a una Región y abarca todas sus Zonas de disponibilidad. Al crearla se define uno o más bloques CIDR IPv4 y, opcionalmente, IPv6. Dentro de la VPC se crean subredes, tablas de enrutamiento, grupos de seguridad y ACL de red.

## Beneficios

- Ayuda a proteger y supervisar las conexiones.
- Permite controlar el tráfico y restringir el acceso a las instancias.
- Ofrece control sobre la ubicación de los recursos, la conectividad y la seguridad.

Una VPC incluye automáticamente una tabla de enrutamiento principal, una ACL de red predeterminada, un grupo de seguridad predeterminado y un conjunto de opciones DHCP.
