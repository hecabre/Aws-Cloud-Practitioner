# Amazon VPC

Una **Amazon VPC** permite aprovisionar una sección lógicamente aislada de la nube de AWS, donde se pueden lanzar recursos en una red virtual definida por el usuario.

## Beneficios

- Ayuda a proteger y supervisar las conexiones.
- Permite controlar el tráfico y restringir el acceso a las instancias.
- Ofrece control sobre la ubicación de los recursos, la conectividad y la seguridad.
