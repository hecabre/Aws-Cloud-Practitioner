# Amazon CloudFront

**Amazon CloudFront** es una red de entrega de contenido (CDN) que distribuye contenido mediante una red global de ubicaciones de borde para reducir la latencia de los usuarios.

Una distribución define uno o más orígenes, como Amazon S3 o un servidor HTTP. Cuando un objeto no está en caché, CloudFront lo solicita al origen y puede almacenarlo en una ubicación de borde o en una caché de borde regional. La clave de caché y la configuración de la distribución determinan cuándo ocurre un cache hit.
