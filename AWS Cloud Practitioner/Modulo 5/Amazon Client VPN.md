# Amazon Client VPN

**Amazon Client VPN** es un servicio de red elástico y [[Servicio completamente administrado]] que permite a los usuarios remotos conectarse de forma segura a una VPC y, mediante el enrutamiento configurado, a redes locales.

## Beneficios

- Proporciona acceso remoto seguro y autenticación.
- Se adapta a la demanda de los usuarios sin que sea necesario administrar la infraestructura de VPN.

## Caso de uso

Puede utilizarse para ampliar rápidamente el acceso seguro de trabajadores remotos a los recursos de AWS.
