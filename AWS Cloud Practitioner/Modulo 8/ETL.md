# ETL

**ETL** es el proceso de extracción, transformación y carga de datos. Prepara datos limpios, coherentes y accesibles para su análisis.

## Etapas

1. **Extraer** datos de una o varias fuentes.
2. **Transformar** los datos a un formato uniforme y utilizable.
3. **Cargar** los datos en un sistema de destino.

Las canalizaciones de datos automatizan este proceso para hacerlo repetible y reducir errores manuales.
