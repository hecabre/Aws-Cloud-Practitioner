# Amazon SageMaker JumpStart

## ¿Qué es?

Es un centro de machine learning dentro de [[Amazon Sage Maker]] que ofrece modelos fundacionales, modelos preentrenados y soluciones prediseñadas. Permite evaluar, personalizar e implementar modelos con mayor rapidez.

## Casos de uso

- Implementar rápidamente modelos previamente entrenados.
- Ajustar modelos con datos específicos de un dominio.
- Comparar modelos para experimentos y prototipos de [[ML]].
