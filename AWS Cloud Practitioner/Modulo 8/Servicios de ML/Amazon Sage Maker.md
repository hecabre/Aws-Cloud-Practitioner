# Amazon SageMaker AI

## ¿Qué es?

Es un [[Servicio completamente administrado]] para crear, entrenar e implementar modelos de [[ML]]. Proporciona herramientas integradas para preparar datos, desarrollar modelos, realizar experimentos y administrar flujos de trabajo de machine learning.

## Beneficios

- **Selección de herramientas:** ofrece interfaces con código y sin código para distintos perfiles.
- **Infraestructura administrada:** reduce el trabajo de aprovisionar y operar la infraestructura de ML.
- **Flujos de trabajo repetibles:** ayuda a automatizar y estandarizar prácticas de MLOps y gobernanza.
