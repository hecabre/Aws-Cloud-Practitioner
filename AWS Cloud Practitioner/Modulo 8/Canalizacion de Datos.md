# Canalización de datos

Una **canalización de datos** automatiza el movimiento y procesamiento de datos desde una fuente hasta un destino. Puede implementar procesos de [[ETL]], reducir trabajo manual y hacer repetibles las transformaciones.

## Conceptos relacionados

- **Ingesta:** mueve datos desde el sistema de origen hacia una solución de almacenamiento o procesamiento.
- **Ingesta en tiempo real:** procesa datos con una latencia baja cuando se necesitan de inmediato.
- **Ingesta por lotes:** procesa grupos de datos cuando se tolera cierta latencia.
- **Lago de datos:** almacena grandes cantidades de datos, incluidos datos sin procesar; [[Amazon S3]] es una opción habitual.
- **Almacén de datos:** organiza datos para consultas analíticas; Amazon Redshift es un ejemplo.
