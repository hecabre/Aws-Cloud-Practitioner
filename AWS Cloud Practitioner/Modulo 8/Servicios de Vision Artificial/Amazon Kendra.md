# Amazon Kendra

## ¿Qué es?

Es un servicio de búsqueda empresarial que utiliza machine learning y procesamiento de lenguaje natural para encontrar respuestas en contenido de una organización. Interpreta el contexto de las consultas para ofrecer resultados relevantes.

## Casos de uso

- Búsqueda empresarial inteligente.
- Búsqueda para asistentes y chatbots.
- Integración de búsqueda en aplicaciones.
