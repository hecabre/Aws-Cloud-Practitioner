# IA generativa en AWS

## Servicios

- **[[Amazon SageMaker JumpStart]]:** centro de [[ML]] con modelos fundacionales, modelos preentrenados y soluciones que pueden implementarse con rapidez.
- **[[Amazon Bedrock]]:** servicio completamente administrado para crear aplicaciones con modelos fundacionales mediante API.
- **[[Amazon Q]]:** familia de asistentes de IA generativa para tareas empresariales y de desarrollo.
