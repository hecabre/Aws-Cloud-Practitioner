# Amazon Q

## ¿Qué es?

Es una familia de asistentes de IA generativa orientados al trabajo empresarial y al desarrollo de software.

## Servicios

- **Amazon Q Business:** responde preguntas, resume contenido y realiza acciones utilizando información de fuentes empresariales autorizadas.
- **Amazon Q Developer:** ayuda a comprender, crear, probar y transformar software, y ofrece asistencia para trabajar con AWS.
