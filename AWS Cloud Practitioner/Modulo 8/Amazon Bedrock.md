# Amazon Bedrock

## ¿Qué es?

Es un [[Servicio completamente administrado]] para crear aplicaciones de [[IA Generativa]] con modelos fundacionales (FM) de Amazon y otros proveedores mediante una API unificada. También ofrece capacidades para personalizar modelos y crear agentes con controles de seguridad, privacidad y gobernanza.

## Casos de uso

- Crear aplicaciones que generen texto, imágenes u otros tipos de contenido compatibles.
- Desarrollar asistentes que consulten datos de una organización.
- Crear agentes que ejecuten tareas mediante sistemas y fuentes de datos.
