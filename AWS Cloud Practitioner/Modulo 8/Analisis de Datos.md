# Análisis de datos

El **análisis de datos** transforma datos sin procesar en información útil para descubrir patrones, explicar resultados y apoyar decisiones.

## Casos de uso

- Explicar decisiones de préstamos a los clientes.
- Analizar datos de ensayos clínicos mediante pruebas de hipótesis.
- Hacer transparentes los modelos de evaluación de riesgos.
