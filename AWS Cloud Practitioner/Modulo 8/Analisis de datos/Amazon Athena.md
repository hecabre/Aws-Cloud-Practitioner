# Amazon Athena

## ¿Qué es?

Es un servicio de consultas interactivo y sin servidor que permite analizar datos directamente en [[Amazon S3]] mediante SQL estándar. Con consultas federadas también puede consultar fuentes relacionales, no relacionales, de objetos y personalizadas mediante conectores.

El costo de las consultas depende, entre otros factores, de la cantidad de datos examinados; no es simplemente un cobro por el número de consultas.
