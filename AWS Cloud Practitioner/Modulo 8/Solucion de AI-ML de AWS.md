# Soluciones de IA y ML de AWS

AWS ofrece tres niveles de soluciones según el grado de personalización y control necesario:

- **Servicios de [[IA]] prediseñados:** capacidades ya entrenadas para tareas específicas.
- **Servicios de [[ML]]:** herramientas como Amazon SageMaker AI para crear, entrenar e implementar modelos con infraestructura administrada.
- **Infraestructura y marcos de [[ML]]:** recursos especializados, incluidos chips diseñados para ML, que se integran con marcos de trabajo populares.
