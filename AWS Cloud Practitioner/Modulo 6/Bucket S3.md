# Buckets de Amazon S3

## ¿Qué es un bucket?

Es un contenedor que se utiliza para almacenar [[Objetos S3]]. El nombre de un bucket debe ser único dentro de la partición de AWS correspondiente. Los buckets sirven como unidad básica para organizar datos y controlar el acceso, y pueden contener una cantidad prácticamente ilimitada de objetos.

La clase de almacenamiento se asigna a cada objeto, por lo que un mismo bucket puede contener objetos de distintas clases.

> [!note] Importante
> Al crear un bucket se especifican el nombre y la región de AWS donde residirá. También se pueden configurar características como el control de versiones, el registro y los permisos de acceso.
