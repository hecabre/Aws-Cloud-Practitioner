# Amazon S3 Intelligent-Tiering

## ¿Qué es?

Es una clase de almacenamiento que optimiza costos al mover automáticamente los objetos entre niveles de acceso según cambian sus patrones de uso. No modifica las [[Politicas de Bucket|políticas de bucket]].

Es apropiada cuando los patrones de acceso son desconocidos o cambian con el tiempo.
