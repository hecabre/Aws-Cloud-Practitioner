# Amazon S3 Standard-IA

## ¿Qué es?

Es una clase de almacenamiento para datos a los que se accede con poca frecuencia, pero que deben recuperarse en milisegundos cuando se necesitan. Su costo de almacenamiento es menor que S3 Standard, aunque cobra por recuperación y tiene una duración mínima de almacenamiento.

## Casos de uso

- Copias de seguridad.
- Datos de recuperación ante desastres.
- Archivos de larga duración que necesitan acceso rápido.
