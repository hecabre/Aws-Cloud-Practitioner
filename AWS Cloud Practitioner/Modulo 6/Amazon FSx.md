# Amazon FSx

Amazon FSx es una familia de [[Servicio completamente administrado|servicios completamente administrados]] de [[Almacenamiento de archivos|almacenamiento de archivos]] basada en sistemas de archivos conocidos.

## Sistemas disponibles

- **FSx for Windows File Server:** ofrece sistemas de archivos de Windows accesibles mediante SMB.
- **FSx for Lustre:** está orientado a cargas de computación de alto rendimiento y procesamiento rápido de datos.
- **FSx for NetApp ONTAP:** proporciona características y protocolos de NetApp ONTAP, incluidos NFS, SMB e iSCSI.
- **FSx for OpenZFS:** ofrece sistemas de archivos administrados basados en OpenZFS y accesibles mediante NFS.

La elección depende del sistema de archivos, los protocolos y las características que requiere la carga de trabajo.
