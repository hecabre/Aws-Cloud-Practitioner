# Clases de almacenamiento S3 Glacier

## ¿Qué son?

Son clases de almacenamiento de [[Amazon S3]] optimizadas para datos de archivo. La opción adecuada depende de la frecuencia de acceso y del tiempo de recuperación requerido.

Pueden utilizarse para archivos multimedia, imágenes médicas, copias de seguridad y datos sujetos a conservación a largo plazo.

## Clases principales

- **S3 Glacier Instant Retrieval:** acceso inmediato para archivos que se consultan rara vez.
- **[[Amazon S3 Glacier Flexibal Retrival|S3 Glacier Flexible Retrieval]]:** recuperación en minutos u horas.
- **[[Amazon S3 Glacier Deep Archive|S3 Glacier Deep Archive]]:** archivos de muy largo plazo con recuperación en horas.
