# Amazon S3 on Outposts

## ¿Qué es?

Lleva el almacenamiento de objetos de [[Amazon S3]] a entornos locales mediante AWS Outposts. Utiliza las API y características de S3 y está pensado para cargas de trabajo con requisitos de residencia local de datos, procesamiento local o rendimiento cercano a las aplicaciones instaladas en las propias instalaciones.
