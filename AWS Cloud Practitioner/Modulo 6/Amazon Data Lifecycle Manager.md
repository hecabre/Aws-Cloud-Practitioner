# Amazon Data Lifecycle Manager

Amazon Data Lifecycle Manager automatiza la administración del ciclo de vida de las **instantáneas de Amazon EBS** y de las **AMI respaldadas por EBS** mediante políticas.

Las políticas pueden seleccionar volúmenes o instancias mediante etiquetas y definir cuándo crear y cuánto tiempo conservar las instantáneas o las AMI. También admiten acciones como la copia entre regiones, según el tipo de política.

## Beneficios

- Programa la creación automática de instantáneas o AMI respaldadas por EBS.
- Configura reglas de retención y eliminación.
- Aplica políticas de respaldo coherentes sin depender de scripts personalizados.
- Ayuda a administrar funciones avanzadas como el archivado o la copia de instantáneas, cuando la política las admite.
