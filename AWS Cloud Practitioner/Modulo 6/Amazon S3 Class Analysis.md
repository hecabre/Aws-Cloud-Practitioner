# S3 Storage Class Analysis

## ¿Qué es?

Analiza los patrones de acceso de los objetos de un [[Bucket S3]] para ayudar a decidir cuándo conviene mover datos de S3 Standard a S3 Standard-IA. Sus recomendaciones pueden utilizarse para mejorar las reglas de [[Ciclo de Vida de S3]], pero el análisis no mueve los objetos automáticamente.
