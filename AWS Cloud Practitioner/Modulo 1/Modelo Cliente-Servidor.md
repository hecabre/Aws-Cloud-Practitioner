# Modelo Cliente-Servidor

El modelo **cliente-servidor** describe cómo un cliente solicita servicios y un servidor los proporciona.

En AWS, el cliente consume servicios desde su equipo o aplicación, y los servidores de AWS entregan el cómputo, almacenamiento u otros recursos solicitados.

## Ideas clave

- Se paga por el uso real.
- Crear más instancias o recursos es sencillo.
- Eliminar recursos también es sencillo.
- Cuando eliminas los recursos, dejas de pagar por ellos.
