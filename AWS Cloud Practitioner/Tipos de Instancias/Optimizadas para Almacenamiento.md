# Instancias Optimizadas para Almacenamiento

Están pensadas para cargas de trabajo con **datos almacenados localmente**, con alto rendimiento de disco y acceso de baja latencia a grandes conjuntos de datos.

## Casos de uso

- Análisis de datos.
- Data warehousing.
- Sistemas de archivos distribuidos.
