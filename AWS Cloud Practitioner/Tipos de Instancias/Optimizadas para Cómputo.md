# Instancias Optimizadas para Cómputo

Son ideales para tareas con **uso intensivo de CPU**.

## Casos de uso

- Tareas de alto procesamiento computacional.
- Servidores de juego.
- Computación de alto rendimiento.
- Modelado científico.

> Destacan en CPU, pero no están pensadas para cargas que exigen alto rendimiento de disco con grandes volúmenes de datos.
