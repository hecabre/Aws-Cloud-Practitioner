# Instancias Optimizadas para Memoria

Están diseñadas para cargas de trabajo que requieren **mucha memoria** y ofrecen buen rendimiento para manejar grandes volúmenes de datos.

## Casos de uso

- Análisis en tiempo real.
- Bases de datos en memoria.
- Cachés.
