# Resumen Rápido

- La nube es **entrega bajo demanda** con **pago por uso**.
- Los tres modelos de despliegue son **nube, híbrido y on-premises**.
- En el [[Responsabilidad Compartida|modelo de responsabilidad compartida]], AWS protege la nube y el cliente protege lo que pone en la nube.
- Una [[Regiones y Zonas de Disponibilidad|región]] agrupa centros de datos; una zona de disponibilidad es un grupo aislado de centros de datos dentro de una región.
- Varias zonas de disponibilidad permiten **alta disponibilidad**.
- [[Amazon EC2]] es cómputo en la nube basado en instancias, es decir, máquinas virtuales.
- El [[Hipervisor]] aísla y reparte los recursos de hardware entre instancias.
- La [[Tenencia Múltiple]] permite compartir infraestructura manteniendo aislamiento lógico.
- Las instancias se agrupan en familias: [[Uso General]], [[Optimizadas para Cómputo]], [[Optimizadas para Memoria]], [[Optimizadas para Almacenamiento]] y [[Computación Acelerada]].
