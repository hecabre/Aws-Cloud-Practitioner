# Tipos de Instancias

Cada familia de instancias está optimizada para un tipo de carga de trabajo.

| Tipo | ¿Para qué sirve? |
| --- | --- |
| [[Uso General]] | Equilibrio entre cómputo, memoria y red. |
| [[Optimizadas para Cómputo]] | Alto rendimiento de CPU. Ideales para servidores de juegos, inferencia de machine learning y modelado científico. |
| [[Optimizadas para Memoria]] | Procesamiento de grandes volúmenes de datos en memoria, como bases de datos en memoria y cachés. |
| [[Optimizadas para Almacenamiento]] | Alto rendimiento de disco y baja latencia. |
| [[Computación Acelerada]] | Uso de GPU, FPGA o chips especializados. |
