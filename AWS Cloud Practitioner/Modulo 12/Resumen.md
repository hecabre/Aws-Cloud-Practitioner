# Resumen de migración

## Recursos oficiales

| Recurso                                                                                                                                                                      | Descripción                                                                                                                                                                                                                                                                                                                                                                                                             |
| ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| [Las tres fases de la migración](https://docs.aws.amazon.com/prescriptive-guidance/latest/strategy-migration/overview.html)                                                 | Una migración a gran escala se organiza en tres fases: evaluar, movilizar, y migrar y modernizar.                                                                                                                                                                                                                                                                                                                        |
| [AWS Cloud Adoption Framework](https://aws.amazon.com/cloud-adoption-framework/)                                                                                             | AWS CAF reúne experiencia y prácticas recomendadas para evaluar la preparación, identificar oportunidades de transformación y crear una hoja de ruta de adopción de la nube.                                                                                                                                                                                                                                           |
| [Siete estrategias de migración (7 R)](https://docs.aws.amazon.com/prescriptive-guidance/latest/large-migration-guide/migration-strategies.html)                              | Las siete estrategias son reubicar, realojar, redefinir la plataforma, refactorizar o rediseñar, recomprar, retener y retirar.                                                                                                                                                                                                                                                                                           |
| [AWS Migration Evaluator](https://aws.amazon.com/migration-evaluator/)                                                                                                       | Ayuda a crear un caso empresarial basado en datos mediante el análisis del entorno actual y el modelado de costos y dimensionamiento para escenarios de migración.                                                                                                                                                                                                                                                       |
| [AWS Application Discovery Service](https://aws.amazon.com/application-discovery/)                                                                                           | Recopila datos de configuración, rendimiento y conexiones de los servidores locales para crear un inventario e identificar aplicaciones y dependencias.                                                                                                                                                                                                                                                                |
| [AWS Application Migration Service](https://aws.amazon.com/application-migration-service/)                                                                                   | Replica servidores de origen de forma continua, permite probarlos y los lanza como instancias de Amazon EC2 para reducir los procesos manuales y el tiempo de inactividad.                                                                                                                                                                                                                                               |
| [AWS Migration Hub](https://aws.amazon.com/migration-hub/)                                                                                                                   | Ofrece una ubicación central para descubrir servidores, planificar migraciones y seguir el progreso de las aplicaciones mediante herramientas de AWS y de socios.                                                                                                                                                                                                                                                       |
| [AWS Database Migration Service (AWS DMS)](https://aws.amazon.com/dms/)                                                                                                      | Permite descubrir, evaluar, convertir y migrar datos entre almacenes compatibles, además de realizar migraciones únicas o replicar cambios continuos.                                                                                                                                                                                                                                                                   |
| [AWS Schema Conversion Tool (AWS SCT)](https://docs.aws.amazon.com/SchemaConversionTool/latest/userguide/CHAP_Welcome.html)                                                   | Herramienta descargable heredada para evaluar y convertir esquemas y objetos de código. AWS recomienda DMS Schema Conversion para las combinaciones compatibles.                                                                                                                                                                                                                                                        |
| [AWS DataSync](https://aws.amazon.com/datasync/)                                                                                                                             | Automatiza y acelera transferencias seguras de archivos y objetos hacia, desde y entre servicios de almacenamiento de AWS.                                                                                                                                                                                                                                                                                              |
| [AWS Transfer Family](https://aws.amazon.com/aws-transfer-family/)                                                                                                           | Proporciona transferencias administradas mediante SFTP, FTPS, FTP, AS2 y navegador web directamente hacia y desde Amazon S3 o Amazon EFS.                                                                                                                                                                                                                                                                                 |
| [AWS Direct Connect](https://aws.amazon.com/directconnect/)                                                                                                                  | Establece conectividad de red privada entre una ubicación y AWS como alternativa al transporte por la Internet pública.                                                                                                                                                                                                                                                                                                 |
| [Cambio de disponibilidad de AWS Snowball Edge](https://docs.aws.amazon.com/snowball/latest/developer-guide/snowball-edge-availability-change.html)                          | Snowball Edge permitía transferir grandes volúmenes sin conexión, pero ya no está disponible para clientes nuevos. AWS recomienda evaluar DataSync, AWS Data Transfer Terminal o soluciones de socios según el caso.                                                                                                                                                                                                    |
