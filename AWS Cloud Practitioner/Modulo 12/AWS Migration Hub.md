# AWS Migration Hub

## ¿Qué es?

Proporciona una ubicación central para descubrir servidores, planificar migraciones y seguir el estado de las migraciones de aplicaciones realizadas con distintas herramientas de AWS y de socios.

## Beneficios

- Centraliza las métricas y el progreso de los proyectos de migración.
- Permite elegir las herramientas de migración apropiadas sin perder una vista unificada.
- AWS Migration Hub Journeys ofrece plantillas, tareas y colaboración para planificar y ejecutar el recorrido de migración.

## Caso de uso

Planificar, coordinar y seguir una migración desde un único lugar.
