# AWS Application Discovery Service

## ¿Qué es?

Ayuda a planificar migraciones mediante la recopilación de información sobre servidores en centros de datos locales, como su configuración, uso, rendimiento y conexiones. Estos datos permiten identificar aplicaciones y dependencias.

## Beneficios

- Crea un inventario de la infraestructura local.
- Ayuda a mapear conexiones y dependencias entre servidores.
- Integra la información de descubrimiento con [[AWS Migration Hub]] para apoyar la planificación.

## Caso de uso

Descubrir el entorno local y reunir datos para evaluar y planificar una migración a AWS.
