# Siete estrategias de migración

Las **7 R** son estrategias para decidir qué hacer con cada carga de trabajo. La elección depende de los objetivos empresariales, la complejidad técnica, el tiempo, el costo y los recursos disponibles.

## Las 7 R

- **Reubicar (relocate):** trasladar una colección de servidores o cargas a AWS sin rediseñarlas; por ejemplo, mover máquinas virtuales a un entorno compatible en AWS.
- **Realojar (rehost):** mover una aplicación con pocos o ningún cambio, también conocido como *lift and shift*.
- **Redefinir la plataforma (replatform):** realizar optimizaciones específicas para obtener beneficios de la nube sin cambiar la arquitectura principal.
- **Refactorizar o rediseñar (refactor/re-architect):** modificar la arquitectura y el código para aprovechar capacidades nativas de la nube.
- **Recomprar (repurchase):** sustituir la aplicación por otro producto, con frecuencia una solución SaaS.
- **Retener (retain):** mantener temporalmente la carga en el entorno de origen y revisarla más adelante.
- **Retirar (retire):** eliminar una aplicación que ya no es necesaria.
