# Transferencia de datos sin conexión

La transferencia física puede ser apropiada cuando el volumen de datos, el tiempo disponible o la conectividad hacen impráctica una transferencia por red.

Los dispositivos [[Dispositivos de Snowball Edge Storage Optimized|Snowball Edge Storage Optimized]] han permitido realizar este tipo de migración. Sin embargo, ya no están disponibles para clientes nuevos; AWS recomienda evaluar AWS Data Transfer Terminal o soluciones de socios para nuevas transferencias físicas.
