# Transferencia de datos hacia y desde AWS

AWS ofrece distintos servicios para transferir datos en línea. La elección depende del tipo de datos, los protocolos existentes, el volumen, la frecuencia y los requisitos de conectividad.

1. **[[AWS DataSync]]:** automatiza transferencias de archivos y objetos entre sistemas de almacenamiento.
2. **[[AWS Transfer Family]]:** conserva flujos de transferencia de archivos mediante protocolos como SFTP, FTPS, FTP y AS2.
3. **[[AWS Direct Connect]]:** proporciona conectividad de red privada entre una ubicación y AWS, que puede utilizarse para transferencias continuas y predecibles.
