# AWS DataSync

## ¿Qué es?

Es un servicio seguro y de alta velocidad para transferir archivos y objetos hacia, desde y entre servicios de almacenamiento de AWS. Puede mover datos entre almacenamiento local, otros proveedores de nube y servicios como [[Amazon S3]], Amazon EFS y Amazon FSx.

## Beneficios

- Automatiza la transferencia y la infraestructura necesaria para realizarla.
- Protege los datos en tránsito y valida su integridad.
- Permite programar tareas, filtrar datos, limitar el ancho de banda y generar informes.

## Casos de uso

- Migrar datos a AWS.
- Archivar datos inactivos.
- Replicar datos y administrar flujos de trabajo híbridos.
