# AWS Migration Evaluator

## ¿Qué es?

AWS Migration Evaluator ayuda a crear un caso empresarial basado en datos para planificar una migración a AWS. Recopila o utiliza datos del entorno actual y modela escenarios de costos y dimensionamiento para el entorno objetivo.

## Beneficios

- Reduce las conjeturas al evaluar la migración.
- Compara escenarios de migración y costos proyectados.
- Ayuda a ajustar el tamaño de los recursos y a evaluar opciones para reutilizar licencias existentes.

## Casos de uso

- Obtener una instantánea del entorno local.
- Estimar el costo total de propiedad y crear un caso empresarial.
- Identificar oportunidades de dimensionamiento y optimización de licencias.
