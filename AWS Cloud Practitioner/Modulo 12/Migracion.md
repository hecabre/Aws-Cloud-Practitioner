# Migración a AWS

AWS ofrece servicios, herramientas y orientación para respaldar una migración durante sus distintas fases.

## Fases

### 1. Evaluar

Se analiza el entorno actual, la preparación de la organización y el caso empresarial para la migración. [[AWS Migration Evaluator]] puede ayudar a crear un caso empresarial basado en datos.

### 2. Movilizar

Se corrigen brechas de preparación, se establece la base del entorno de AWS y se prepara a los equipos, los procesos y el portafolio de aplicaciones. [[AWS Application Discovery Service]] y [[AWS Migration Hub]] pueden ayudar con el descubrimiento y la planificación.

### 3. Migrar y modernizar

Se utilizan la estrategia, el plan y las prácticas recomendadas para migrar las cargas por oleadas, operarlas y modernizarlas cuando corresponda.
