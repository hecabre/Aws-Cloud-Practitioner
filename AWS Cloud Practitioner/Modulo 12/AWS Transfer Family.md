# AWS Transfer Family

## ¿Qué es?

Es un servicio completamente administrado para transferir archivos directamente hacia y desde [[Amazon S3]] o [[Amazon Elastic File System (EFS)]]. Admite SFTP, FTPS, FTP, AS2 y transferencias mediante navegador web.

## Beneficios

- Evita administrar la infraestructura de servidores de transferencia.
- Permite conservar clientes y flujos de trabajo de transferencia existentes.
- Se integra con mecanismos de autenticación, cifrado, supervisión y control de acceso.

## Casos de uso

- Modernizar flujos de trabajo de transferencia de archivos.
- Intercambiar archivos con clientes y socios.
- Incorporar datos empresariales a un lago de datos.
