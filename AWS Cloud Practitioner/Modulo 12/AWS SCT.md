# AWS Schema Conversion Tool (AWS SCT)

## ¿Qué es?

AWS SCT es una herramienta descargable que evalúa y convierte esquemas de bases de datos y objetos de código, como procedimientos almacenados, vistas y funciones, para hacerlos compatibles con otro motor. Su informe de evaluación ayuda a estimar el esfuerzo de conversión manual.

> [!warning]
> AWS considera AWS SCT una herramienta heredada y recomienda usar **DMS Schema Conversion** para las conversiones compatibles. AWS SCT todavía admite más combinaciones de origen y destino.

## Beneficios

- Automatiza gran parte del análisis y la conversión del esquema.
- Identifica los objetos que requieren intervención manual.
- Admite motores de bases de datos y servicios analíticos compatibles.

## Caso de uso

Convertir una base de datos comercial a un motor de código abierto compatible como parte de una migración heterogénea.
