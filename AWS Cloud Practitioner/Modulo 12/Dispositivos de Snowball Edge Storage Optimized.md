# Dispositivos Snowball Edge Storage Optimized

## ¿Qué son?

Son dispositivos físicos de AWS Snowball Edge diseñados para transferir grandes cantidades de datos sin conexión y ejecutar determinadas cargas en el borde. Los datos se copian al dispositivo y este se envía a AWS para importarlos.

> [!warning] Disponibilidad
> AWS Snowball Edge ya no está disponible para clientes nuevos. AWS recomienda evaluar AWS DataSync para transferencias en línea, AWS Data Transfer Terminal o soluciones de socios para transferencias físicas, y AWS Outposts para cómputo en el borde. Los clientes existentes pueden seguir utilizándolo según las condiciones del servicio.

## Beneficios

- Permite transferir grandes volúmenes cuando la red no es suficiente o no está disponible.
- Ofrece almacenamiento de alto rendimiento y capacidad de cómputo en el borde.

## Caso de uso

Migraciones de datos sin conexión para clientes existentes que ya utilizan Snowball Edge.
