# AWS Application Migration Service

## ¿Qué es?

AWS Application Migration Service simplifica la migración de servidores y aplicaciones a AWS mediante la replicación continua de servidores de origen en un área de preparación de la cuenta de AWS. Después permite realizar pruebas y lanzar las cargas migradas en Amazon EC2.

## Beneficios

- Reduce los procesos manuales y el tiempo de inactividad mediante replicación continua.
- Admite sistemas operativos e infraestructuras de origen compatibles, tanto locales como en otras nubes.
- Permite ejecutar acciones de modernización antes o después del lanzamiento de las instancias migradas.

## Casos de uso

- Migrar servidores físicos, virtuales o basados en la nube a AWS.
- Migrar cargas entre regiones de AWS compatibles.
