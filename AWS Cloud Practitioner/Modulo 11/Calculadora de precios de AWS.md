# AWS Pricing Calculator

## ¿Qué es?

Es una herramienta web de planificación que permite crear estimaciones de costos de AWS. Se pueden agregar configuraciones específicas, como tipos de instancia, opciones de almacenamiento y volúmenes de transferencia de datos, para obtener un desglose de los costos estimados.

> [!important]
> Las estimaciones dependen de la configuración y no sustituyen la factura por el uso real.

## Casos de uso

- Estimar costos antes de una implementación.
- Comparar servicios y configuraciones de AWS.
- Preparar presupuestos y evaluar escenarios.
