# Red de socios de AWS

## ¿Qué es?

La **AWS Partner Network (APN)** es una comunidad global de socios que aprovechan tecnologías, programas, experiencia y herramientas de AWS para crear soluciones y servicios para los clientes.

Los clientes pueden trabajar con socios de AWS para encontrar soluciones especializadas. Las organizaciones que participan como socios pueden acceder, según su nivel y los programas aplicables, a beneficios como:

- recursos de financiación y comercialización;
- eventos, seminarios web y talleres para socios;
- formación y certificación orientadas a socios.
