# AWS Cost Explorer

## ¿Qué es?

Permite visualizar y analizar los costos y el uso de AWS mediante gráficos, filtros, informes y previsiones. Ayuda a identificar patrones de gasto y tendencias, y ofrece recomendaciones de optimización para determinados compromisos de precios.

## Casos de uso

- Analizar tendencias históricas de costos y uso.
- Desglosar el gasto por servicio, región o cuenta vinculada, entre otras dimensiones.
- Prever costos futuros a partir de patrones históricos.
