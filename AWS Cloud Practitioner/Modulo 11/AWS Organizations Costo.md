# AWS Organizations y costos

## ¿Qué es?

AWS Organizations proporciona administración y gobernanza centralizadas para varias cuentas de AWS. Permite crear y agrupar cuentas, aplicar políticas de forma centralizada y usar la facturación consolidada.

Con la **facturación consolidada**, la cuenta de administración recibe una sola factura y paga los cargos de las cuentas miembro. Además, el uso de algunas cuentas puede combinarse para aplicar descuentos por volumen o beneficios de precios, según el servicio.

## Casos de uso

- Consolidar varias cuentas de AWS en una organización.
- Centralizar la facturación y los pagos.
- Aplicar políticas en toda la organización.
