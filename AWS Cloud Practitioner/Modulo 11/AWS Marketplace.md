# AWS Marketplace

## ¿Qué es?

Es un catálogo digital de software, datos y servicios de terceros que permite buscar, probar, comprar e implementar soluciones que se ejecutan en AWS.

## Tipos de soluciones

- **Software como servicio (SaaS):** herramientas de marketing, colaboración y aplicaciones empresariales.
- **Machine learning (ML) e IA:** modelos prediseñados para tareas como el reconocimiento de imágenes y el procesamiento de lenguaje natural.
- **Datos y análisis:** conjuntos de datos y plataformas de inteligencia empresarial para análisis y visualización.
