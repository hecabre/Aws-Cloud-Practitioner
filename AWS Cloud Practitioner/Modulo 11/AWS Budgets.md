# AWS Budgets

## ¿Qué es?

Permite establecer presupuestos personalizados y enviar alertas cuando los costos o el uso reales o previstos superan los umbrales definidos. También permite supervisar la cobertura y la utilización de Savings Plans y reservas.

## Casos de uso

- Configurar alertas cuando los costos reales o previstos superen los umbrales definidos.
- Supervisar el gasto y el uso en relación con un presupuesto.
- Controlar la cobertura y la utilización de Savings Plans y reservas.
