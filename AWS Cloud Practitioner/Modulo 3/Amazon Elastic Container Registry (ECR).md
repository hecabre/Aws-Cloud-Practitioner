# Amazon Elastic Container Registry (ECR)

Amazon Elastic Container Registry (Amazon ECR) es un registro administrado, seguro y escalable para almacenar, compartir y administrar **imágenes de contenedores** y artefactos compatibles con OCI.

ECR almacena las imágenes, pero no ejecuta los contenedores. Para desplegarlas puede utilizarse un servicio de orquestación o ejecución como:

- [[Amazon Elastic Container Service (ECS)]].
- [[Amazon Elastic Kubernetes Service (EKS)]].
