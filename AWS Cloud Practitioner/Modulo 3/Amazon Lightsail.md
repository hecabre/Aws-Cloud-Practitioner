# Amazon Lightsail

Amazon Lightsail ofrece recursos simplificados para crear sitios web y aplicaciones, como servidores privados virtuales, servicios de contenedores, bases de datos administradas, almacenamiento, balanceadores de carga, CDN, direcciones IP estáticas y DNS.

Los paquetes agrupan recursos por un precio mensual predecible, aunque pueden existir cargos adicionales según el consumo y los servicios utilizados.

## ¿Cuándo es ideal?

Es adecuado para usuarios que buscan una experiencia de AWS sencilla y para cargas de trabajo básicas o predecibles, como:

- Sitios web y blogs.
- Aplicaciones web sencillas.
- Entornos de desarrollo y pruebas.
- Proyectos de pequeñas empresas.
- Aprendizaje y primeros proyectos en la nube.
