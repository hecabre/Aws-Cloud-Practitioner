# AWS Elastic Beanstalk

AWS Elastic Beanstalk es un [[Servicio administrado]] para desplegar y administrar aplicaciones web en AWS.

El cliente carga el código y selecciona una plataforma. Elastic Beanstalk crea y configura los recursos necesarios, como instancias de [[Amazon EC2]], balanceadores de carga, grupos de Auto Scaling y monitoreo del estado de la aplicación.

El cliente conserva acceso y control sobre los recursos subyacentes creados en su cuenta.

## ¿Cuándo es ideal?

Es adecuado para desplegar y administrar:

- Aplicaciones web.
- API REST.
- Servicios de backend.
- Aplicaciones basadas en microservicios.

## Ventajas

- Reduce el trabajo necesario para aprovisionar y configurar la infraestructura.
- Automatiza el balanceo de carga, el escalamiento y el monitoreo del entorno.
- Permite controlar y personalizar los recursos subyacentes.
