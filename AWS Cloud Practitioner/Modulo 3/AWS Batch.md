# AWS Batch

AWS Batch es un [[Servicio completamente administrado]] de cómputo por lotes que planifica, programa y ejecuta cargas de trabajo en contenedores.

En un entorno de cómputo administrado, AWS Batch aprovisiona los recursos y optimiza la distribución de los trabajos según la cantidad y los requisitos de las cargas. Puede utilizar capacidad de Amazon ECS, Amazon EKS, [[AWS Fargate]] o [[Amazon EC2]].

## ¿Cuándo es ideal?

Es adecuado para cargas de trabajo paralelas y de gran escala, como:

- Computación científica.
- Análisis de riesgos financieros.
- Transcodificación de medios.
- Procesamiento de macrodatos.
- Entrenamiento de machine learning.
- Investigación genómica.

## Ventajas

- No es necesario instalar ni administrar software de procesamiento por lotes.
- Programa los trabajos mediante colas y aprovisiona capacidad según la configuración del entorno de cómputo.
- Permite concentrarse en los trabajos y sus resultados en lugar de administrar el programador por lotes.
