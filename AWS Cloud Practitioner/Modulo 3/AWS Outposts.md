# AWS Outposts

AWS Outposts es una familia de soluciones [[Servicio completamente administrado|completamente administradas]] que extiende la infraestructura, los servicios, las API y las herramientas de AWS a las instalaciones del cliente.

AWS opera, monitorea y administra la capacidad de cómputo y almacenamiento de Outposts como parte de una Región de AWS. El cliente proporciona y administra el espacio físico, la energía y la conectividad que requiere el sitio.

## ¿Cuándo es ideal?

Es adecuado para cargas de trabajo que requieren:

- Baja latencia con sistemas locales.
- Procesamiento local de datos.
- Residencia de datos.
- Migración de aplicaciones con dependencias de sistemas locales.
- Una experiencia híbrida coherente con las API y herramientas de AWS.
