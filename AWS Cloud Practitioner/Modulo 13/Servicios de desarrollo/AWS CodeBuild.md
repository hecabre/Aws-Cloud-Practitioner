# AWS CodeBuild

AWS CodeBuild es un [[Servicio completamente administrado|servicio completamente administrado]] de compilación que compila código fuente, ejecuta pruebas y produce artefactos listos para implementar. Aprovisiona y escala los recursos de compilación, por lo que no es necesario administrar servidores de compilación.

Puede formar parte de un flujo de integración continua y se cobra según los recursos y el tiempo de compilación consumidos.
