# AWS CodePipeline

AWS CodePipeline es un [[Servicio completamente administrado|servicio completamente administrado]] de entrega continua que modela y automatiza las etapas de un proceso de lanzamiento, como origen, compilación, prueba y despliegue. Se integra con servicios de AWS y herramientas de terceros para entregar cambios de forma repetible.

> [!note]
> Las canalizaciones de **CI/CD** automatizan la integración, las pruebas y la entrega o implementación de cambios de código.
