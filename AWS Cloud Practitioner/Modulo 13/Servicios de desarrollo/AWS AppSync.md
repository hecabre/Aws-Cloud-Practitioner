# AWS AppSync

AWS AppSync es un [[Servicio completamente administrado|servicio completamente administrado]] para crear API de GraphQL y de eventos Pub/Sub sin administrar servidores. Una API de GraphQL puede acceder, manipular y combinar de forma segura datos de varios orígenes.

> [!note]
> **GraphQL** es un lenguaje de consulta para API que permite a los clientes solicitar los datos específicos que necesitan.
