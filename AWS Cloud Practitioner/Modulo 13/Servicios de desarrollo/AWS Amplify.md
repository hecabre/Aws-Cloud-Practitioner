# AWS Amplify

AWS Amplify proporciona herramientas y servicios para crear, implementar y alojar aplicaciones web y móviles de pila completa en AWS. Permite definir o integrar funciones como datos, autenticación, almacenamiento y alojamiento del frontend con menos administración directa de infraestructura.

> [!note]
> Una aplicación de **pila completa** incluye tanto el frontend, o interfaz de usuario, como el backend, o lógica y servicios del lado del servidor.
