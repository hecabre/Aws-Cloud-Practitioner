# AWS IoT Core

AWS IoT Core es un [[Servicio completamente administrado|servicio administrado]] que permite conectar dispositivos con aplicaciones en la nube e intercambiar mensajes de forma segura. Admite protocolos como MQTT, MQTT sobre WebSocket seguro y HTTPS.

Las conexiones utilizan TLS y, según el protocolo y la configuración, pueden autenticar los dispositivos mediante certificados X.509, identidades de Amazon Cognito o autenticación personalizada. Las reglas de AWS IoT pueden dirigir los mensajes a otros servicios de AWS para procesarlos y tomar acciones.
