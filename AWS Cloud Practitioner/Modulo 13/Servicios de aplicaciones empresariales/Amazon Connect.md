# Amazon Connect

Amazon Connect es un centro de contacto omnicanal basado en la nube. Permite configurar y operar interacciones de servicio al cliente mediante canales como voz, chat, SMS, video, tareas y correo electrónico.

Incluye capacidades para enrutamiento, grabación y análisis de interacciones, así como funciones de [[IA]] para autoservicio y asistencia a agentes.
