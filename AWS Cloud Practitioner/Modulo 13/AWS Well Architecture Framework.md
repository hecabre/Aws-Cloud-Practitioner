# AWS Well-Architected Framework

## ¿Qué es?

Es un marco de prácticas recomendadas y preguntas de diseño para evaluar cargas de trabajo y tomar decisiones de arquitectura fundamentadas. Ayuda a comprender las ventajas y desventajas de las decisiones y a identificar oportunidades de mejora.

## Pilares

1. **Excelencia operativa:** ejecutar y supervisar sistemas, entregar valor empresarial y mejorar continuamente los procesos.
2. **Seguridad:** proteger los datos, los sistemas y los activos mediante la gestión de riesgos y controles adecuados.
3. **Fiabilidad:** lograr que las cargas realicen su función prevista, se adapten a cambios y se recuperen de fallos.
4. **Eficiencia del rendimiento:** utilizar los recursos de cómputo de manera eficiente y mantener esa eficiencia a medida que cambian las necesidades.
5. **Optimización de costos:** evitar gastos innecesarios y obtener valor empresarial con el costo apropiado.
6. **Sostenibilidad:** minimizar el impacto ambiental de las cargas mediante un uso eficiente de los recursos.

## ¿Cómo se usa?

AWS Well-Architected Tool permite documentar una carga y responder preguntas basadas en los pilares y las lentes seleccionadas. El resultado identifica riesgos y ofrece orientación para mejorar; no ejecuta ni prueba automáticamente la carga de trabajo.
