# Amazon WorkSpaces applications

**Amazon WorkSpaces applications**, anteriormente llamado **Amazon AppStream 2.0**, es un [[Servicio completamente administrado|servicio completamente administrado]] para transmitir aplicaciones y escritorios no persistentes desde AWS a dispositivos compatibles.

Permite entregar aplicaciones de escritorio mediante un navegador o cliente y convertirlas en una experiencia de tipo SaaS sin reescribir su código.
