# Amazon WorkSpaces Secure Browser

Es un [[Servicio completamente administrado|servicio completamente administrado]] de navegador remoto empresarial. Proporciona un entorno aislado para acceder a sitios web privados, aplicaciones SaaS y la Internet pública desde el navegador local del usuario.

El contenido web se procesa en AWS y se transmiten píxeles cifrados al dispositivo. Esto reduce la exposición de los datos y evita administrar software cliente especializado o infraestructura de navegador remoto; la conectividad con recursos privados todavía debe configurarse.
