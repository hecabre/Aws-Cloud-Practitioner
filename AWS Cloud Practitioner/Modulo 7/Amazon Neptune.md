# Amazon Neptune

## ¿Qué es?

Amazon Neptune es un [[Servicio completamente administrado|servicio completamente administrado]] de bases de datos de grafos diseñado para conjuntos de datos altamente conectados, como los de las redes sociales.

Facilita consultar relaciones difíciles de modelar mediante tablas relacionales, como conexiones entre personas, rutas de red o dependencias. Admite modelos de grafo de propiedades y RDF, así como lenguajes de consulta compatibles con esos modelos.

## Beneficios

1. Se destaca en el almacenamiento y la consulta de datos altamente conectados mediante modelos gráficos.
2. Su almacenamiento distribuido crece automáticamente hasta 128 TiB en la mayoría de las regiones y replica los datos entre tres zonas de disponibilidad de una misma región.
3. Admite copias de seguridad automatizadas, instantáneas manuales y cifrado para proteger los datos.
