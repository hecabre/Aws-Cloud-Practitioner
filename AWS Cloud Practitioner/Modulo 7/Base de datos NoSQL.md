# Bases de datos NoSQL

## ¿Qué son?

Las bases de datos NoSQL utilizan modelos de datos distintos del modelo relacional, como clave-valor, documentos, columnas anchas o grafos. Suelen diseñarse para patrones de acceso específicos, esquemas flexibles y escalado horizontal.

Las bases de datos relacionales organizan los datos en tablas relacionadas y normalmente utilizan SQL. No son inherentemente poco escalables ni lentas; la elección depende de las relaciones, las consultas y los requisitos de consistencia de la carga.

En una base de datos clave-valor o de documentos, cada elemento puede contener una colección de atributos con nombres y valores. Los elementos de una misma colección no siempre necesitan compartir todos los atributos, y algunos motores utilizan documentos similares a JSON.
