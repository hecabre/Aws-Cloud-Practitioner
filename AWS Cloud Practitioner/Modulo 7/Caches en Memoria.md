# Cachés en memoria

## ¿Qué son?

Una caché en memoria es una capa de almacenamiento de alta velocidad que guarda temporalmente en RAM los datos a los que se accede con frecuencia. Al atender lecturas desde memoria, puede reducir la latencia y la carga sobre la base de datos o el sistema de almacenamiento principal.

> [!important]
> La caché no suele ser la fuente duradera de los datos. La aplicación debe definir cómo actuar ante datos ausentes, vencidos o desactualizados.
