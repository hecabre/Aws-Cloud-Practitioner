# AWS Database Migration Service (AWS DMS)

## ¿Qué es?

AWS Database Migration Service ayuda a migrar bases de datos relacionales, almacenes de datos, bases NoSQL y otros almacenes de datos hacia AWS, entre entornos locales y la nube, o entre servicios de AWS.

Admite migraciones únicas y la replicación continua de cambios para reducir el tiempo de inactividad. En migraciones heterogéneas, DMS Schema Conversion puede evaluar y convertir el esquema antes de que AWS DMS transfiera los datos.
