# Amazon DocumentDB

## ¿Qué es?

Amazon DocumentDB es un [[Servicio completamente administrado|servicio completamente administrado]] de base de datos de documentos con compatibilidad con MongoDB. Permite almacenar, consultar e indexar documentos similares a JSON con esquemas flexibles.

Es apropiado para aplicaciones con datos orientados a documentos y esquemas que evolucionan. No debe confundirse con una base de datos relacional: DocumentDB pertenece a la categoría NoSQL.
## Casos de uso
1. Sistemas de administración de contenido.
2. Administración de catálogos.
3. Administración de inventarios.
4. Sistemas de perfiles.
## Beneficios
1. Es compatible con las API de MongoDB admitidas, aunque existen diferencias funcionales que deben evaluarse al migrar.
2. Permite agregar hasta 15 réplicas de lectura que comparten el almacenamiento subyacente del clúster.
3. En los clústeres basados en instancias, el almacenamiento crece automáticamente en incrementos de 10 GB hasta 256 TiB en la versión 8.0 y hasta 128 TiB en versiones anteriores.
