# Amazon Relational Database Service (RDS)

## ¿Qué es?

Amazon RDS es un [[Servicio administrado|servicio administrado]] de bases de datos relacionales que facilita tareas como el aprovisionamiento de hardware, la aplicación de parches, las copias de seguridad y la recuperación. Admite distintos tipos de instancia optimizados para memoria, cómputo o rendimiento de E/S.

## ¿Qué ofrece?

- **Disponibilidad y recuperación:** implementaciones Multi-AZ, copias de seguridad automatizadas e instantáneas manuales.
- **Seguridad:** aislamiento de red y opciones de cifrado en tránsito y en reposo.

## Motores compatibles

1. MySQL
2. PostgreSQL
3. Microsoft SQL Server
4. MariaDB
5. [[Amazon Aurora]]
6. Oracle Database
