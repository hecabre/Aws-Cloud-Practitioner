# Amazon Aurora

## ¿Qué es?

Amazon Aurora es un motor de base de datos relacional [[Servicio completamente administrado|completamente administrado]] por Amazon RDS y compatible con MySQL y PostgreSQL. Separa el cómputo del almacenamiento distribuido para ofrecer alto rendimiento y disponibilidad.

En un clúster regional, Aurora replica el almacenamiento en seis nodos distribuidos entre tres zonas de disponibilidad de una misma región. Para replicación entre regiones se debe configurar una característica como Aurora Global Database.

El almacenamiento crece automáticamente según los datos del clúster. Aurora también ofrece copias de seguridad automatizadas, cifrado en reposo y supervisión.
