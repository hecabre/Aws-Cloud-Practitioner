# AWS Backup

## ¿Qué es?

AWS Backup centraliza y automatiza la protección de datos de los servicios de AWS compatibles y de determinadas cargas locales. Permite administrar desde un solo lugar los planes, la supervisión y el cumplimiento de las copias de seguridad.

Admite servicios como [[Amazon Ebs|Amazon EBS]], [[Amazon Elastic File System (EFS)]] y varias bases de datos. Ofrece programación flexible, políticas de retención, cifrado y, para los recursos compatibles, copias entre regiones y cuentas.
