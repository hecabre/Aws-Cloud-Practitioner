# Amazon FSx

Amazon FSx es una familia de [[Servicio completamente administrado|servicios completamente administrados]] de [[Almacenamiento de archivos|almacenamiento de archivos]] basada en sistemas de archivos conocidos.

## Sistemas disponibles

- FSx for Windows File Server
- FSx for Lustre
- FSx for NetApp ONTAP
- FSx for OpenZFS

Cada opción está orientada a necesidades distintas, como aplicaciones de Windows, computación de alto rendimiento o cargas de trabajo que ya utilizan tecnologías NetApp u OpenZFS.
