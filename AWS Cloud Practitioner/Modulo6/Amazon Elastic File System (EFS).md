# Amazon Elastic File System (EFS)

Amazon Elastic File System (Amazon EFS) es un [[Servicio completamente administrado|servicio completamente administrado]] y elástico de [[Almacenamiento de archivos|almacenamiento de archivos]] para cargas de trabajo basadas en Linux.

Utiliza el protocolo NFS y permite que varios recursos de AWS accedan al mismo sistema de archivos. También puede utilizarse desde servidores locales conectados a una VPC mediante AWS Direct Connect o AWS Site-to-Site VPN.
