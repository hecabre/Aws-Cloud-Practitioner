# AWS Control Tower

## ¿Qué es?

Es un servicio que permite configurar y gobernar un entorno de múltiples cuentas de AWS. Crea una zona de aterrizaje basada en prácticas recomendadas y aplica controles preventivos, de detección y proactivos.

## Beneficios

- Acelera la creación de un entorno de múltiples cuentas.
- Automatiza el aprovisionamiento de cuentas con gobernanza integrada.
- Proporciona controles preconfigurados y visibilidad del cumplimiento.

## Casos de uso

- Aprovisionar cuentas que sigan las normas de la organización.
- Aplicar controles de seguridad, operaciones y cumplimiento a escala.
- Implementar cargas de trabajo con una base de gobernanza común.
