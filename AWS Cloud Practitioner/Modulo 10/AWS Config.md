# AWS Config

## ¿Qué es?

Es un servicio que registra las configuraciones de recursos de AWS y sus cambios a lo largo del tiempo. Mediante reglas de AWS Config, también puede evaluar esas configuraciones frente al estado deseado.

## Beneficios

- Mantiene un historial de configuración de los recursos compatibles.
- Evalúa recursos mediante reglas administradas o personalizadas.
- Facilita la investigación de cambios, la auditoría y la corrección.

## Casos de uso

- Supervisar continuamente la configuración de recursos.
- Evaluar requisitos de seguridad y cumplimiento.
- Investigar problemas operativos y administrar cambios.
