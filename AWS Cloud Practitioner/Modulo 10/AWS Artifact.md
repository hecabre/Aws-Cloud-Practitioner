# AWS Artifact

## ¿Qué es?

Es un servicio que proporciona acceso bajo demanda a informes de seguridad y cumplimiento de AWS, así como a determinados acuerdos en línea. AWS Artifact no realiza auditorías: entrega documentación que puede utilizarse como evidencia.

## Beneficios

- Facilita el acceso a informes de cumplimiento actualizados.
- Ayuda a administrar acuerdos y documentación de cumplimiento a escala.
- Permite compartir artefactos de AWS con auditores o reguladores.

## Componentes

### Acuerdos

Permite revisar, aceptar y administrar determinados acuerdos para una cuenta individual o para las cuentas de una organización en [[AWS Cloud Practitioner/Modulo 10/AWS Organizations]], según el acuerdo y los permisos disponibles.

### Informes

Ofrece informes de cumplimiento elaborados por auditores independientes que evalúan los controles de AWS frente a estándares y normativas específicos.

## Casos de uso

- Obtener documentación de cumplimiento de AWS.
- Administrar acuerdos disponibles en línea.
- Evaluar la seguridad y el cumplimiento de proveedores de AWS.
