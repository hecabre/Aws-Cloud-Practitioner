# AWS Trusted Advisor

## ¿Qué es?

Es un servicio que inspecciona el entorno de AWS y ofrece recomendaciones basadas en prácticas recomendadas. Sus comprobaciones abarcan optimización de costos, rendimiento, seguridad, tolerancia a errores y límites de servicio.

La cantidad de comprobaciones y funciones disponibles depende del plan de AWS Support. Todas las cuentas tienen acceso a un conjunto básico; determinados planes de soporte ofrecen el conjunto completo.

## Beneficios

- Ayuda a priorizar recomendaciones para mejorar el entorno.
- Facilita la optimización de recursos y costos.
- Detecta oportunidades para mejorar seguridad, rendimiento y resiliencia.

## Casos de uso

- Revisar recursos infrautilizados.
- Identificar configuraciones de seguridad que requieren atención.
- Supervisar límites de servicio y tolerancia a errores.
