# Analizador de acceso de IAM

## ¿Qué es?

IAM Access Analyzer ayuda a establecer, verificar y refinar permisos. Analiza políticas mediante razonamiento automatizado para identificar acceso externo, interno o no utilizado, según el tipo de analizador, y valida políticas de [[AWS Iam]].

## Beneficios

- Identifica recursos accesibles desde fuera de una zona de confianza.
- Detecta acceso y permisos no utilizados.
- Valida políticas y ayuda a aplicar el principio de privilegio mínimo.

## Casos de uso

- Verificar quién puede acceder a un recurso.
- Validar políticas antes de implementarlas.
- Corregir accesos externos no deseados.
- Refinar permisos amplios o no utilizados.
