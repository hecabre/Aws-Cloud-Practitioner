# Gobernanza

La **gobernanza en la nube** define y aplica políticas, responsabilidades y controles para que el uso de la nube se mantenga alineado con los objetivos empresariales, de seguridad, operaciones y cumplimiento.

En AWS, [[AWS Cloud Practitioner/Modulo 10/AWS Organizations]] y [[AWS Control Tower]] ayudan a establecer una estructura de múltiples cuentas y aplicar controles de forma centralizada.
