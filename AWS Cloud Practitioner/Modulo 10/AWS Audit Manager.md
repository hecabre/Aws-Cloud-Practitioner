# AWS Audit Manager

## ¿Qué es?

Es un servicio que ayuda a auditar de forma continua el uso de AWS mediante la recopilación y organización automatizada de evidencia. Facilita la evaluación de controles, riesgos y requisitos de cumplimiento, pero no determina por sí solo si una organización cumple una normativa.

## Beneficios

- Reduce el trabajo manual de recopilación de evidencia.
- Facilita la colaboración entre equipos y delegados de auditoría.
- Organiza la evidencia mediante marcos, controles y evaluaciones.

## Casos de uso

- Automatizar la recopilación de evidencia para auditorías.
- Realizar evaluaciones continuas de controles.
- Preparar informes de evaluación para auditores.
