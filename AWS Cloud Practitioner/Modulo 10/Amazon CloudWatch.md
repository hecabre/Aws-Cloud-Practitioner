# Amazon CloudWatch

## ¿Qué es?

Es un servicio de monitoreo y observabilidad que recopila datos operativos de recursos, aplicaciones y servicios. Proporciona una vista unificada del uso de recursos, el rendimiento de las aplicaciones y el estado operativo.

## Características

- **Métricas:** valores numéricos medidos a lo largo del tiempo.
- **Alarmas:** acciones o notificaciones cuando una métrica cumple una condición.
- **Paneles:** visualizaciones personalizadas de métricas y alarmas.
- **Logs:** recopilación, consulta y análisis de registros.

## Beneficios

- Centraliza métricas y registros.
- Aumenta la visibilidad de aplicaciones, infraestructura y servicios.
- Ayuda a reducir el tiempo medio de resolución (MTTR).
- Genera información para optimizar aplicaciones y recursos.
