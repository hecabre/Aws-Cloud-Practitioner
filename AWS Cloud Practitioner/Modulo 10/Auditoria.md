# Auditoría

La **auditoría** es el proceso de recopilar y examinar evidencia para comprobar si las actividades, configuraciones y controles de un entorno se ajustan a políticas y requisitos definidos.

En AWS, servicios como [[Aws CloudTrail]], [[AWS Config]], [[AWS Artifact]] y [[AWS Audit Manager]] aportan registros, historial de configuración, informes y evidencia para este proceso.
