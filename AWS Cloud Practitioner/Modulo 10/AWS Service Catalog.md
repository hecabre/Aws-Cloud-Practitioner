# AWS Service Catalog

## ¿Qué es?

Es un servicio que permite crear, organizar, gobernar y compartir catálogos de productos de infraestructura como código aprobados para su uso en AWS.

## Beneficios

- Facilita el autoservicio de productos aprobados.
- Mantiene controles de gobernanza sobre los recursos aprovisionados.
- Estandariza los recursos que pueden implementar los equipos.

## Casos de uso

- Aprovisionar productos aprobados en cuentas de AWS.
- Aplicar controles de acceso sobre catálogos y productos.
- Distribuir recursos básicos de red y seguridad.
- Acelerar el aprovisionamiento de canalizaciones de integración y entrega continuas.
