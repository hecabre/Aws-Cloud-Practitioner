# AWS License Manager

## ¿Qué es?

Es un servicio que ayuda a administrar licencias de software de proveedores como Microsoft, SAP, Oracle e IBM en AWS y en entornos locales.

## Beneficios

- Mejora la visibilidad y el control sobre el uso de licencias.
- Automatiza el seguimiento de licencias según reglas definidas.
- Reduce el riesgo de incumplimiento y ayuda a controlar costos.

## Casos de uso

- Centralizar la administración de licencias.
- Simplificar la movilidad de licencias de Microsoft mediante Software Assurance.
- Distribuir y activar derechos de software entre cuentas de AWS.
