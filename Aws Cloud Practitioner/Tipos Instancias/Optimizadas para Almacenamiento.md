Son ideales para cargas de trabajo para datos almacenados localmente
> Son ideales para:
> - Analisis de datos.
> Las instancias optimizadas para el almacenamiento están diseñadas para cargas de trabajo que requieren un alto rendimiento de disco y un acceso de baja latencia a grandes conjuntos de datos. Esto las convierte en la mejor opción para las aplicaciones de análisis de datos.
