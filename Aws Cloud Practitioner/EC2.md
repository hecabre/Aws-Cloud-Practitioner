Significa Amazon elastic compute cloud
Un EC2 son basicamente **maquinas virutales en la nube** . Pero enves de una maquina virtual es una instancia, asi se hacen llamar en AWS.
> **Caracteristicas:**
> - Altamente flexible
> - Rapida
> - Rentable
- Solo pagas por las **instancias en ejecucion**.
- Son maquinas virtuales que comparten hardware.
- Un ordenador fisico tienen muchas maquinas virtuales.
Aws administra el [[Hipervisor]] y es aislamientro entre instancias,
[[Tenencia Multiple]]:
Se puede tener el SO de linux o windows, tambien podemos configurar que software se puede ejecutar en ese software.
Son redimensionables, podemos cambiar de tamaño, si necesita mas recursos; simplente le damos mas recursos eso es **escalamiento vertical**
